# 中等不利组合检查U2

用户已选择A组合检查：585 W向阳可用功率、270 Wh可用电池容量、初始电量70%、公共负载＋10%同时生效。以A2_NORMAL_120为控制与物理基准，10%额外预留、120秒展开、10秒确认、600秒超时、轨道/燃料/帆及365天上限不变。

四项均为研究压力条件，没有统计发生概率依据；不代表实际卫星的已知老化组合，也不把本案例通过/失败写成真实可靠性百分比。容量变化不修改卫星质量，公共负载变化不修改推进器350 W或机构30 W。

实际模式负载：安全等待251 W、推进581 W、展开261 W；电池初始189 Wh，保护线54 Wh。注意不能把上次四项单独通过推导为组合通过，也不能将各单因素延迟简单相加预测组合结果。

运行：`startup; root=run_uncertainty_u2;`。新建u2目录，保存实际案例配置、轨迹、逐段电量、事件、能量审计和60/30秒对照。资源不足时保留power_failure；未到达时间保持NaN。失败原因核对后再讨论改进，不在本实验中更改硬件或成功标准。

验收：19项现有回归测试、组合值与主案例其他参数一致性检查、独立能量/燃料/事件审计；60/30秒对照状态一致，终止时间差≤max(60秒,1%)、燃料差≤max(0.0001kg,1%)。阶段结果未完成前不标通过。

本组独立运行，暂不更新run_current的23案例定义或旧复现包。实际结果和限制在完成后追加。
