# 最终证据总表（当前成果冻结快照）

本稿整理已完成的A1、A2、U1、U2实验，不是新一次仿真，也不宣称所有参赛材料、硬件认证或跨机复现已完成。结论限于已保存配置。后续修改须另存新结果，不按本表反向调整参数。

## 主结论

资源约束下的帆推协同方案在当前研究场景中可运行：当前主案例约9.83天到达120 km，耗推进剂约0.442 kg；所设中等不利组合约13.34天，时间增加约35.7%。这不是实际飞行承诺或真实可靠性百分比。

## 核心结果

## 结论—证据—限制

| 可讲的结论 | 使用什么对照 | 不可扩大为 |
|---|---|---|
| 提前留电改善所设500 W情景 | A1_OLD_500与A1_NEW_500_R10，同电池同负载；旧缺供，新到达 | 所有500 W卫星都可行，或全来自增加硬件 |
| 正常有限展开影响较小 | A2_IDEAL与A2_NORMAL_120，约晚69秒 | 任意机构展开都瞬时可靠 |
| 明确故障后补推有资源代价 | A2_PARTIAL更快但燃料更多；A2_FAILED更慢且接近燃料预算 | 故障有益，或真实帆与推进器干涉安全已证明 |
| 反馈未知不等于真实未展开 | A2_LOST_DEPLOYED与A2_LOST_STOWED：同样未知停推，约9.83/66.32天 | 控制器已诊断真实面积，或超时停推对所有机构绝对安全 |
| 中等单因素下仍完成 | U1四个独立变化，约9.84–11.53天，无基础缺供 | 已覆盖全部不确定性，或成功率100% |
| 所设组合仍完成但明显变慢 | U2与主案例：延长3.5074天、约35.67%，保护线余量约16.56 Wh | 找到可承受极限，或实际可靠性已认证 |
