推荐10个案例：基准＋8个单因素＋中等不利组合（585 W、270 Wh、70%、公共负载＋10%）。另一选项为基准＋4个中等单因素共5例，较快但不验证较大或叠加情景。

以上为团队研究压力范围，没有实测分布或概率依据；不得将通过比例作为实际可靠性。不能称这些变化覆盖全部真实不确定性。固定阴影、姿态与大气不在本批新增因素内，其限制继续存在。

输出：任务状态、窗口退出、120 km时间、燃料、累计点火、最低电量及相对保护线余量、基础缺供、展开是否发令/确认与原因。失败作为结果保留；同硬件/控制规则对照，不临时增大电池或减少负载。

实现注意：目前部分额外监测负载为固定5 W，公共负载变化时不能重复缩放它。控制许可、提前储备和实际电池积分必须从同一经扰动账本读取；仅改展示表而不改变实际负载不能算完成扫描。

验收：基准复现；输入合法性、逐段能量和燃料账核对；关键边界/异常案例的60/30秒一致性检查沿用原阈值。任何跨阈值情景须报告不稳定性，不能事后放宽标准。
