# 评委提问与证据边界（2026-09-30）

> 本文保留早期阶段口径；当前准备答辩请优先使用[当前问答稿](评委答辩问答稿_当前版.md)和[最终证据总表](最终证据总表.md)。下文旧数据不删除，不与后来的A1/A2/U1/U2控制条件混比。

本稿只覆盖仿真代码、参数来源、工程可行性和创新性。数字来自 `results/defense_20260930/tables/` 的候选输入仿真，不是飞行保证。

| 可能提问 | 有证据的回答 | 尚缺什么 |
|---|---|---|
| 为什么选 550 km、50 kg 和 500–600 km？ | 这是团队选取的代表卫星和初始轨道窗口。比赛主题二覆盖 200–2000 km 低轨，但没有指定这些数值。`config/baseline_case.m` 固定输入，四策略使用同一卫星。 | 代表性与目标用户场景仍需更具体的外部资料。 |
| 大气表能证明 8.89 天吗？ | 不能。`input_audit.csv` 将候选大气表标为 `unverified`；密度倍率 0.5–2 的情景把 P 到 120 km 的时间从约 11.83 天变到约 7.42 天。 | 原始出版表、单位转换、适用环境和更真实的大气模型核对。 |
| 哪个推进器能同时达到 20 mN、1200 s、350 W？ | 当前没有完成同一器件工作点核实。理想喷流功率约 117.68 W，小于候选输入功率，但这只说明数量级没有直接违反能量约束。 | 具体型号、效率、质量、寿命、热约束和电源处理单元资料。 |
| 50 kg、650 W 和 10 m² 帆真的能实现吗？ | 候选账本列项为 48 kg，账面余量 2 kg；向阳 S1 负载 560 W，对 650 W 候选可用功率余量 90 W。`engineering_summary.csv` 仍是 `unverified`，10 m² 是假设的额外有效迎风面积。 | 寿命末期及食期供电、真实设备质量、帆展开与姿态保持证据。 |
| 如果推进器或电力出问题会怎样？ | 固定模拟观测下，`SUP_THRUSTER_FAILED` 立即展帆，约 89.93 天到 120 km；`SUP_THRUST_POWER_LOW` 的 500 W 不足以许可推进，`SUP_ATTITUDE_UNAVAILABLE` 也不推进，两者在 365 天计算上限内都未观测到窗口退出或到达 120 km。 | 真实电力时序、传感器、姿态与故障诊断模型；目前只是预置情景。 |
| 350 km 展帆是不是整圈轨道都降到 350 km？ | 不是。代码在瞬时密切半长轴首次下穿 350 km 时切换；切换后约一圈内，约 75% 时间该量仍高于 350 km。`switch_diagnostic.csv` 保存了检查结果。 | 若改成整圈平均或远地点触发，须作为新策略重新比较。 |
| 为什么说协同方案有价值？ | 同一候选输入下，P 与 B2 都约 2.759 天退出原窗口；P 约 8.890 天到 120 km、用 0.444 kg 推进剂，B2 约 10.906 天、用 0.800 kg。七点切换扫描展示时间与燃料取舍。 | 这些优势只对当前模型和参数范围成立，不等于全局最优或已通过硬件认证。 |
| 创新是否只是两种已有技术拼接？ | 不声称发明新的推进原理。可验证的工作是分阶段交接、事先定义的切换与故障规则、同条件对照和资源取舍；监督器在模拟观测下已驱动独立轨道案例。 | 需对照现有公开方案，具体说明系统设计或策略选择上的差异。 |
| B0 的 365 天和 120 km 分别代表什么？ | B0 在 365 天计算上限内没有观测到窗口退出或 120 km 事件；120 km 是本模型的积分终点，不证明完全烧毁、落区安全或碰撞风险降低。 | 120 km 以下再入和实际空间交通风险需独立研究，不属于现有仿真。 |

答辩时只引用已生成的表格及其候选输入状态。窗口退出是密切远地点的事后评价指标，不是实时安全保证；B1 在 500 km 边界附近受 J2 振荡影响，窗口时间只报约 56.4 天，不报秒级精度。未在计算上限内发生的事件记为“未观测到”，不能写成 365 天完成。

`evidence_context.csv` 同时记录 Git 提交号和工作目录是否有未提交修改。若 `workingTreeState=modified`，该提交号不是当前运行代码的完整快照；跨电脑复现仍需另行执行并记录差异。

## 本轮更新

上述表格为 defense_20260930 的阶段结果。后续补证已找到 CelesTrak 大气数据且 14 行数值一致，取得 BHT-200 厂家工作点，增加了同帆面积折减和电池/阴影监督案例。最新细节与剩余边界以《资料核对与工程补证报告》为准；不要继续回答“完全没有找到大气数据出处”，也不要反过来声称大气模型、整套推进系统、电池或帆姿态已完成认证。

若评委问供电模型是否真实：它是明示的固定圆轨道阴影与候选电池收支模型，500 W 下能发现基础缺供并标记 power_failure；这说明测试会揭露不利结果，不代表已解决所有低功率故障。
