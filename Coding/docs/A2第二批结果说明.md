# A2第二批：有限时长展帆与反馈分离

本批用户已确认650 W＋10%余量主案例，以及60/120/300秒展开、10秒反馈延迟和600秒确认超时。参数仍为研究假设，240 W总展开功率来自现有候选账本（公共210 W＋机构30 W）。没有修改Reference最终目标原文。

## 模型和控制

- 实际面积由模拟环境决定，控制器只读取观测。默认面积随受电展开时长线性增长，另保留完成前不计面积的对照；不是机械结构仿真。
- 展开前保守按无太阳补电估算完成展开、正常确认等待及额外余量所需电量；不足时不发令。电机仅工作所设时长，等待反馈用SAFE负载，不无限耗电。
- 正常反馈在实际过程结束后10秒到达；明确半展开或失败才允许健康、姿态、燃料和供电条件下补推。半展开补推多计5 W帆监测负载。
- 两个无反馈案例分别设实际全展/未展，控制器都只看到unknown并保持停推。600秒确认超时不能被当成实际面积为零。
- 完整展开前不得出现完整面积，供电中断时power_failure停止；不继续按完整成功过程传播。电量追踪覆盖实际消耗，但未模拟失电后的真实机构惯性动作。

## 如何理解结果

正常展开的分钟级差异可能仅造成很小离轨时间变化，不能因为影响小而跳过过程验证。半展开后若补推，到达可能更快，但代价是更多燃料/点火，不能称故障反而更好。无反馈却实际已展开的案例即使到120 km，也仅说明该设定下被动轨道到达，不证明星上控制器已知道展开成功。

独立验证将检查实际面积与反馈时间、单次发令、有限机构耗电、未知反馈停推、能量账与电池边界。正常120秒、半展开与500 W案例进行60/30秒复算，判据沿用终止时间max(60秒,1%)、燃料max(0.0001kg,1%)，不根据结果放宽。

## 已保存案例的阶段结果

本轮目录 `results/a2_20260930_185136_511/`。截至阶段核对，理想基准9.831665天、正常60/120/300秒约9.832059/9.832460/9.833700天，四者燃料约0.441840 kg。半展开约9.447567天、0.594879 kg；明确失败约12.514924天、0.790051 kg。它们均无记录到基础缺供。半展开更快是补推带来的时间—燃料交换，不是故障有益。

已展开但反馈丢失约9.832460天，实际过程120秒结束、电机停止；600秒超时、无确认、不自动补推。该结果不代表控制器知道真实展开成功。实际未展开且丢失反馈约66.324666天到120 km，燃料仍约0.441840 kg：控制器同样未知、停推，但实际面积不同导致明显时间差异。500 W正常120秒展开约28.465367天、0.430728 kg、最低电量81.099 Wh，无基础缺供。

正常120秒与半展开的60/30秒时间差分别约2.9707秒、1.7121秒，燃料差约2.12e-7 kg、2.91e-6 kg；500 W时间差12.693秒、燃料差约4.41e-13 kg，三项均通过既定阈值。

## 最终验收

17项模块测试通过，十案例独立部署/能量审计全部通过（deployment_audit.csv），三项数值对照全部通过（resolution_check.csv）。机构额外能耗60/120/300秒分别0.5/1/2.5 Wh；等待反馈不继续计入电机功率。全部案例本次均到120 km且无基础缺供，但不据此推导真实成功率。

保守的“完成前不计新增面积”对照约9.833256天，比线性展开120秒约慢69秒；面积时间模型影响在本情景中小于故障反馈与补推代价。旧理想A1主案例逐指标复现一致。

长期未展开无反馈情景计算较慢，批处理在其保存完成后被停止；续跑核对参数后复用完成案例。优化仅让展开已结束的固定面积直接进入原受力函数，等价断言通过，未更改控制、物理值或上限。旧日志、续跑日志均保留。
