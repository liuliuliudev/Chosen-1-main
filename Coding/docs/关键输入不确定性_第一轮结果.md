## 目前可以说明什么

- 本组四个单因素变化下，控制仍到达120 km且未记录基础缺供。这里是所设模型的可用范围样本，不是成功率100%的证明。
- 向阳功率下降10%造成约1.69天延迟，是本次有限扫描中最大的时间影响；不能据此给所有任务或所有变化幅度排序。
- 电池270 Wh时保护线为54 Wh，而300 Wh时为60 Wh，必须比较保护线余量，不能仅比较最低绝对电量。
- 初始电量70%的最低电量反而略高，可能来自控制早期停推/充电时序变化；闭环控制不要求该输出随初始电量单调。不能据此推导越少初始电量越好。
- 公共负载210 W增加10%后，所有模式公共部分同步增加21 W：等待251 W、推进581 W、展开261 W。推进器350 W、电机30 W本体值不变。
- 四项单独通过，不能推出它们同时发生时通过；组合条件、严重退化、动态太阳几何、真实姿态等未在本轮核验。
