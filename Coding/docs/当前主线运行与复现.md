- `resultRoot=run_current;`：当前演示和控制验证，完整重建A1八案例、A2十案例、能量/展开审计、必要60/30秒对照及过程图。自动创建current_时间目录。是完整验证入口，低功率与未展开长期案例可能耗时数十分钟，不宜答辩现场临时全量计算。

- 已保存结果和图用于现场解释；不能把重播已有结果称作当场重新仿真。

## 复现包

打包命令为 `python Coding/scripts/export_reproduction.py <完整current结果目录>`。缺少18案例参考表、索引或通过的审计时拒绝打包。包内包含代码、配置、目标文档、公开资料副本、A1/A2参考指标、文件SHA-256清单。

用 `python Coding/scripts/verify_reproduction_package.py <ZIP路径或解压目录>` 检查文件；这是字节一致性检查，不是仿真验证。另一台电脑解压后运行run_current，再按《跨机复现说明》运行compare_current_reproduction；记录设备、MATLAB版本、耗时和差异，才能确认跨机复现。

历史基础复现包不能替代当前A1/A2包。`reproduction_20260930_201122.zip`是打包反例意外产生的诊断包，缺少当前参考值，禁止使用；旁边已保留说明文件。
